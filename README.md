# เว็บส่งความคิดถึง 💌

หน้าเว็บภาษาไทยพร้อมคลิปแมว ปุ่มหลบ และข้อความส่งความคิดถึง รองรับมือถือและคอมพิวเตอร์

## เปิดใช้งานบน GitHub Pages

1. อัปโหลด `index.html`, `cat.mp4`, `.nojekyll` และ `อิอิ.html` ไปไว้ที่หน้าแรกของ repository บน branch `main`
2. เปิด **Settings → Pages**
3. ที่ **Source** เลือก **Deploy from a branch**
4. เลือก branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอ GitHub เผยแพร่เสร็จ แล้วเปิดลิงก์ที่หน้า Pages แสดง

ที่อยู่เว็บสำหรับ repository นี้: https://bibizamalaw-prog.github.io/miss-you/

## ไฟล์

- `index.html` — หน้าเว็บหลัก รวม CSS และ JavaScript แล้ว ไม่ต้องติดตั้งหรือ build
- `cat.mp4` — คลิปแมวที่ใช้ในหน้าเว็บ ต้องอยู่โฟลเดอร์เดียวกับ `index.html`
- `อิอิ.html` — ส่งต่อจากชื่อไฟล์เดิมมายังหน้าเว็บหลัก
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์เว็บโดยตรง

เปิด `index.html` ด้วยเบราว์เซอร์เพื่อทดลองในเครื่องได้เช่นกัน ฟอนต์ Prompt โหลดจาก Google Fonts และมีฟอนต์สำรองหากออฟไลน์ ฟังก์ชันหลักไม่ต้องใช้บริการภายนอก

วิดีโอเริ่มเล่นแบบปิดเสียงตามข้อจำกัดของเบราว์เซอร์ กดเปิดเสียงที่ตัวควบคุมวิดีโอได้ หากเปิดการลดการเคลื่อนไหวไว้ วิดีโอจะรอให้กดเล่นเองและปุ่มจะไม่เคลื่อนที่
